SupplierVariantSupplement

This has a one to one relationship with SupplierVariant, and provides supplemental data for the SupplierVariant. These items get updated at a lower frequency, and are therefore separate.

type SupplierVariantSupplement {
  averageShippingCost: Float
  barcode: String
  casePack: Int
  cost: Float
  createdAt: String!
  deliveryMethod: VariantDeliveryMethod
  handlingCost: SupplierVariantHandlingCost
  handlingCostAsCurrency: Float
  manufacturer: String
  mapPrice: Float
  mpn: String
  msrp: Float
  productTags: [String]
  recommendedPrice: Float
  shippingDimensions: SupplierVariantShippingDimensions
  sku: String
  standardizedColor: VariantStandardizedColor
  supplierId: ID!
  supplierProductId: ID!
  supplierVariantId: ID!
  taxCode: String
  updatedAt: String!
  updatedBy: String!
  weight: SupplierVariantWeight
}

Fields​

SupplierVariantSupplement.averageShippingCost ● Float scalar​

A calculated metric for some kind of average for a common region. Uncommon.

SupplierVariantSupplement.barcode ● String scalar​

UPC, ISBN, GTIN, etc

SupplierVariantSupplement.casePack ● Int scalar​

Quantity in one variant (i.e. 12-pack)

SupplierVariantSupplement.cost ● Float scalar​

COGS, or Cost of Goods Sold, in a currency

SupplierVariantSupplement.createdAt ● String! non-null scalar​

ISO Date

SupplierVariantSupplement.deliveryMethod ● VariantDeliveryMethod enum​

SupplierVariantSupplement.handlingCost ● SupplierVariantHandlingCost object​

Additional warehouse handling charge, typically for larger items.

SupplierVariantSupplement.handlingCostAsCurrency ● Float scalar​

Calculated field, giving the handling cost as Currency no matter how it is stored

SupplierVariantSupplement.manufacturer ● String scalar​

Often same as vendor, but not always.

SupplierVariantSupplement.mapPrice ● Float scalar​

Minimum Advertised Price

SupplierVariantSupplement.mpn ● String scalar​

Manufacturer Part Number

SupplierVariantSupplement.msrp ● Float scalar​

Manufacturer's Suggested Retail Price

SupplierVariantSupplement.productTags ● [String] list scalar​

SupplierVariantSupplement.recommendedPrice ● Float scalar​

AKA Price

SupplierVariantSupplement.shippingDimensions ● SupplierVariantShippingDimensions object​

SupplierVariantSupplement.sku ● String scalar​

Stock Keeping Unit

SupplierVariantSupplement.standardizedColor ● VariantStandardizedColor enum​

SupplierVariantSupplement.supplierId ● ID! non-null scalar​

SupplierVariantSupplement.supplierProductId ● ID! non-null scalar​

SupplierVariantSupplement.supplierVariantId ● ID! non-null scalar​

SupplierVariantSupplement.taxCode ● String scalar​

Sales Tax Related Code, can match your chosen sales tax provider

SupplierVariantSupplement.updatedAt ● String! non-null scalar​

ISO Date

SupplierVariantSupplement.updatedBy ● String! non-null scalar​

SupplierVariantSupplement.weight ● SupplierVariantWeight object​

Returned by​

createSupplierVariantSupplement mutation ● updateSupplierVariantSupplement mutation ● upsertSupplierVariantSupplements mutation

Member of​

SupplierVariant object ● SupplierVariantComposite object
